## 🚀 Featured Projects

### ⚡ [CodeForge — Real-Time Competitive Programming Platform](https://github.com/Lovejindal1/CodeForge)

A production-ready online judging and algorithmic battle platform inspired by LeetCode and Codeforces.

- **Asynchronous Code Execution:** Background judging queue using **BullMQ + Redis** running C++ compiler inside isolated Docker containers and cloud direct runtime.
- **1v1 Real-Time Battle Arena:** Instant matchmaking with **Socket.io** rooms, live telemetry of opponent test cases, and automatic **ELO rating updates**.
- **ICPC Contests & Leaderboard:** Scheduled programming contests with automated penalty-based leaderboards and node-cron auto-rating jobs.
- **Security & Caching:** JWT token revocation with Redis blacklist and express-rate-limiters.

> **Tech Stack:** React 19, Vite, Node.js, Express, Socket.io, BullMQ, Upstash Redis, MongoDB Atlas, Docker  
> 🔗 **Live Demo:** [code-forge-iota-ten.vercel.app](https://code-forge-iota-ten.vercel.app) | 📦 **Repo:** [Lovejindal1/CodeForge](https://github.com/Lovejindal1/CodeForge)

### ✈️ [Airline Booking System — Microservices Architecture](https://github.com/Lovejindal1/Airline-Booking-System)

A scalable, distributed Airline Booking backend built using modern microservices architecture and message queues.

- **Microservices Design:** Decoupled Flight Service, Booking Service, and Notification Service for independent scalability.
- **Asynchronous Event-Driven Messaging:** Used **RabbitMQ** to publish and consume booking and notification events reliably.
- **Database Architecture:** Relational data modeling with **MySQL** and **Sequelize ORM**, maintaining strong transactional integrity.
- **Cloud Infrastructure:** Deployed on **AWS EC2** with **Amazon RDS** for managed MySQL and **PM2** process management for zero downtime.

> **Tech Stack:** Node.js, Express.js, RabbitMQ, AWS EC2, Amazon RDS, MySQL, Sequelize, PM2, JWT  
> 📦 **Repo:** [Lovejindal1/Airline-Booking-System](https://github.com/Lovejindal1/Airline-Booking-System)
